CaseReady 1.0.1 moves the public application to GitHub Pages and connects it directly with the Client Evidence Registry.

## Changed

- The live application now uses `https://zpthanos.github.io/CaseReady/`.
- CaseReady links to the Client Evidence Registry from the header, product rationale and footer.
- The repository screenshots were recaptured from the final GitHub Pages deployment.
- The static deployment is built from the same tested source and committed as a verified Pages artifact.

## Verification

The deployed application was exercised through the fictional payment-and-order scenario. The live capture covered the home page, blank validation, sensitive-data warning, completed intake, customer confirmation, support brief, engineering escalation and mobile layout. It reported no browser errors and no horizontal overflow at the mobile viewport.

The support workflow, deterministic output rules and privacy model are unchanged from version 1.0.0.
